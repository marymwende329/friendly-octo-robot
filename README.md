Never had room for a real antenna farm, so remote operation always interested me more than it should. Remote Ham Radio solves that by renting time on stations most of us could never build, think stacked Yagis and amplifiers running full legal power, accessed from any browser or the iOS app. RemoteTx is cheaper and more hands on, a Raspberry Pi bridges your own rig to the internet without dealing with Mumble or port forwarding. FlexRadio SmartLink is the easiest if you already own compatible hardware, since it is folded straight into SmartSDR starting version 2.
